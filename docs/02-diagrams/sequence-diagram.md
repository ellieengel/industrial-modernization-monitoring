# Диаграммы последовательности

## 1. Синхронизация фактических данных и обработка отклонений (UC-02, UC-03)

```mermaid
sequenceDiagram
    autonumber
    participant Scheduler as Планировщик
    participant M2 as Модуль 2
    participant ExtAPI as Внешний API
    participant DB as База данных
    participant User as Сотрудник ведомства

    Scheduler->>M2: Ежедневный запуск синхронизации
    M2->>DB: Создать запись sync_run (статус: в процессе)
    M2->>ExtAPI: Запрос фактических данных
    
    alt Данные получены успешно
        ExtAPI-->>M2: JSON с фактическими данными
        M2->>M2: Проверка структуры, единиц измерения и дубликатов
        M2->>DB: Сопоставление external_project_id и сохранение snapshot
        M2->>M2: Пересчёт отклонений (сроки, бюджет, KPI)
        M2->>DB: Сохранение фактов и записей об отклонениях (deviations)
        M2->>DB: Обновить sync_run (статус: успех)
    else Ошибка получения данных
        loop Максимум 3 повтора после первой ошибки
            M2->>ExtAPI: Повторный запрос данных
            ExtAPI-->>M2: Ответ (ошибка или данные)
        end
        M2->>DB: Записать результат попытки
        M2->>DB: Сохранить последнюю успешную версию, пометить источник как устаревший (stale)
        M2->>DB: Обновить sync_run (статус: ошибка)
    end

    opt Обнаружены отклонения
        M2->>DB: Создать записи об отклонениях
        User->>M2: Назначить ответственного за отклонение
        M2->>DB: Записать действия в audit_log
    end
