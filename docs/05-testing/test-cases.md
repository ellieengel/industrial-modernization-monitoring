# Тест-кейсы

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-01 | Импорт валидного утверждённого проекта | Создан внутренний UUID, план и KPI сохранены |
| TC-02 | Перезаписать утверждённую версию | Ошибка/конфликт, значения не изменены |
| TC-03 | Разные внешние ID двух источников для одного проекта | Оба сопоставлены одному project_id; конфликтов между источниками нет |
| TC-04 | Внешний API успешно отвечает | Snapshot и время успеха сохранены |
| TC-05 | Первичная ошибка и три неуспешных повтора | Старые данные сохранены, stale=true, ошибки залогированы |
| TC-06 | План этапа 100 дней, факт 111 | Отклонение 11% регистрируется |
| TC-06a | План 100 дней, факт 110 | При строгом условии >10% отклонение не создаётся |
| TC-06b | Плановая длительность 0 | Ошибка данных, деления на ноль нет |
| TC-07 | План расходов 10 млн, факт 11,2 млн; платежи 8,1 млн | Бюджетное отклонение рассчитывается по расходам |
| TC-07a | План расходов 10 млн, факт 11 млн | При условии >10% отклонение не создаётся |
| TC-08 | HIGHER_IS_BETTER: план 100, факт 85, порог 10% | Неблагоприятное отклонение |
| TC-09 | LOWER_IS_BETTER: план 100, факт 115, порог 10% | Неблагоприятное отклонение |
| TC-09a | LOWER_IS_BETTER: план 100, факт 90 | Снижение не трактуется как ухудшение |
| TC-09b | План KPI равен нулю | Нет деления на ноль; ошибка качества данных/спецправило |
| TC-10 | Создано предложение SUSPENDED без подтверждения | Статус проекта не меняется |
| TC-11 | Подтвердить SUSPENDED без документа | Операция отклоняется |
| TC-11a | Подтвердить TERMINATED_EARLY с основанием, комментарием, документом | Статус и аудит сохранены |
| TC-12 | Назначить ответственного по отклонению | Назначение и история сохранены |
| TC-13 | Ответственный отметил устранение | RESOLVED до проверки; CLOSED только ведомством |
| TC-14 | Представитель предприятия меняет чужой проект/факт | Доступ запрещён |
| TC-15 | Руководитель формирует отчёт | Только проекты его области ответственности |
| TC-16 | Смена статуса и синхронизация | Созданы записи аудита и истории |
| TC-17 | Повторный source_record_id | Дубликат не создаётся |
| TC-18 | Несовместимые валюта или период | Расчёт блокируется, фиксируется ошибка качества данных |

Реальные интеграционные тесты требуют согласованных API-контрактов и тестовых стендов.
